# 固定路径与全局入口

## 每次操作先定位
1. Codex 用户目录是环境变量 `CODEX_HOME`，未设置才用用户主目录下 `.codex`。只读检查其中 `AGENTS.override.md` 和 `AGENTS.md`；第一个非空文件有效。不要硬编码某位作者的用户目录。
2. 从有效全局指令找已有的个人知识库路径（包括没有本 Skill 标记的旧入口），同时检查当前上下文明确指定的位置。已配置的库是默认目标；当前工作目录只是任务目录。明确要求操作另一库时遵从，但不要顺手改变全局默认库。多条入口冲突、无效路径、库目录不可读或无权限时，说明实际路径并等用户修正；不能全盘搜索私人资料、改权限或新建替代库。
3. 没有全局入口时，检查用户指定路径或当前目录是否有知识库入口、六分区或先前零散记录。有则复用，不重置。无库的新建任务优先使用用户明确的路径；未指定时，空的专用知识库目录可采用当前目录；普通代码仓库或工作项目不能当作默认库，先问保存位置。尊重用户磁盘偏好，不假定每台机器都有 D 盘。
4. 与本人、目标、决定、已有项目有关的任务才读库根 `AGENTS.md`、导航、资产和对应项目卡。无关翻译、算术、普通代码修复不读个人资料。记住／灵感／清理／体检全部沿用这一解析结果。

## 搭建或修复接入
默认搭建包括全局接入，采访总结要同时呈现库的绝对路径与接入范围；确认总结之前不写任何文件。明确只要本地库时不写全局入口。已有库且用户明确要求“接入全局”可直接做，不重复采访。安装 Skill 的授权本身不代表可以生成个人资产。

接入前回读两个全局指令文件和库入口。有效文件已有指向同一库的短入口且覆盖按需读写、失效处理时保留它，不能再追加一套。已有非标记入口缺规则时，只定点补充；有冲突先核实，不把下面脚本当作语义冲突检测器。

提供了 Python 标准库助手 `scripts/global_entry.py`，已有 Python 时可用；不为它安装依赖。先运行（参数均用实际绝对路径）：

```text
python scripts/global_entry.py --root <知识库绝对路径> --codex-home <实际Codex用户目录>
```

默认只输出拟写内容；确认已获搭建/接入授权且检查无冲突，再加 `--apply`。脚本只管理 `<!-- ai-knowledge-base:begin -->` 至 `<!-- ai-knowledge-base:end -->` 的短入口，保留其余字节；已有有效 override 就写 override，重复执行不重写，无效根目录拒绝。修改前备份原文，备份在同一用户目录，仅本地保留。不要打包备份、认证或测试日志。

无 Python 时按同样规则直接定点编辑，无需安装软件：选择有效的 override，否则 AGENTS.md；保留全部无关内容和原换行；只维护一个标记块。两文件都有旧标记、隐藏的旧入口指向其他库、标记不完整、路径冲突时先解决，不自动搬移或删除用户文件。脚本拒绝这类结构歧义；非标记入口需人工阅读判断。

短入口内容由脚本 `render` 给出，也可按以下语义填写：固定库绝对路径；相关任务先读库内家规、导航和资产，再按需读项目；无关任务不读；确认过的结论和决定当场写回并标日期；所有知识库口令回到同一库；路径失效停止、不另建；保留项目规则和当前权限；不自动同步或上传。

## 验收与边界
- 回读修改后文件，确认原有规则还在、入口仅一份、根目录可读；重复执行应无变更。
- 全局指令在新会话启动时加载。另一个项目的新会话应能回答已确认的测试资料，执行“记住”后第三个目录的新会话应读到更新。仅测试自己授权的内容；不要为演示写假事实进真实库。
- 项目更近的指令可能覆盖全局规则；权限不足、指令被截断或宿主不支持用户级 AGENTS.md 时，说明限制，不修改安全设置来强行通过。
- 这只是同一可访问本地环境的固定入口，不是模型永久记忆。其他机器、云会话、其他 AI 需要各自配置与数据可访问性；不自动上传、不配置云同步、不保证所有客户端行为一致。

Codex 指令发现依据：[官方 AGENTS.md 文档](https://developers.openai.com/codex/guides/agents-md)。
