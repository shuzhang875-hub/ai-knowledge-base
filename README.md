# AI 知识库 Skill

把说过的背景、做过的决定和正在推进的事存成自己能看懂的 Markdown 文件，让 Codex 在后续聊天里按需读取。

## 安装

把这段发给本地 Codex：

```text
请从 https://github.com/shuzhang875-hub/ai-knowledge-base 安装 ai-knowledge-base Skill 到我的用户级 Skills 目录。先检查已有安装，保留其他 Skill 和设置；遵守我的磁盘存储偏好，必要时用目录链接接入发现目录。只安装本仓库的通用 Skill，不上传本地资料、不复制测试文件，也不要现在替我建知识库。完成后告诉我是否需要重开聊天才能发现它。
```

如果使用支持 GitHub 安装的 Skill Installer，也可以给它上面的仓库地址。仓库根目录就是 Skill（包含 `SKILL.md`、`agents/`、`references/`、`assets/`、`scripts/`）。

安装完成后，创建一个关联专用空文件夹的本地项目，在新聊天里说：

```text
用 $ai-knowledge-base 帮我搭知识库。
```

AI 会从深入理解你的角度采访，一次问一个问题，沿着你的回答追问经历、动机、取舍、实际做法和现实处境；没有固定题数，不会因为几个栏目填完就结束。它判断本轮已有充分、具体的理解后才总结；你随时说“今天先到这里”，它就立即停止新问题，给阶段总结，未问清的留待续聊。一次采访不能保证百分之百了解一个人。

总结同时说明知识库存放路径与全局接入范围。你确认后才建库并配置入口。已有知识库则先读取和复用，避免覆盖或重复建库。你也可以明确指定独立库路径，或说明只要本地库、不接入全局。

## 装好后能做什么

- 六分区：灵感、项目、个人资产、外部资源、归档、固定做法。
- `记住：……`：写入对应文件；变化的事实更新旧句，保留准确时态。
- `帮我把这个丢进灵感库：……`：先收原话。
- `清一下灵感库`：逐条选择留、归、放；放到第二次默认归档，保留资料。
- `知识库体检`：修本地链接与导航、区分当前和历史、列待确认项，结合卡点与已验证复盘改进。
- 每个项目一份当前主记录；逐轮记录问题、原因、解法；环节确定后提炼可复用规则、开工用法和验收方法。

## 跨项目接入

知识库保存在一个固定路径。Codex 用户级 `AGENTS.md`（已有有效 `AGENTS.override.md` 时使用后者）只放短入口，保留原有其他规则。与本人或项目有关的新聊天按需读库，确认过的结论写回同一库；无关任务不读个人资料。换项目不会因此再建一个库。

安装 Skill 与完成全局接入是两步。只有确认搭建或明确要求接入后，才写全局入口；旧聊天可能需要重开。已有入口复用，重复执行不叠加；路径失效时报告，不默默建立替代库。

范围是同一可访问本地环境、同一 Codex 配置。项目指令和权限仍生效；不同电脑、云会话、其他 AI 不会自动同步，也不自动上传个人资料。Obsidian 可打开同一个知识库文件夹查看和编辑，但不是必装依赖。Skill 无需第三方 Python 包；入口助手有现成 Python 时可用，没有时可按文档直接维护入口。

全局指令机制见 [Codex 官方说明](https://developers.openai.com/codex/guides/agents-md)。

## 隐私

此仓库只包含通用规则、空模板和入口维护助手，不包含作者的个人知识库。不要把自己的资产、项目记录、认证文件或备份提交到这个公开仓库。
